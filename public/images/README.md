# Product Images Directory

This directory is for storing your actual Amazon Filter product images.

## How to Add Real Product Images:

1. **Upload your product images** to this directory (`public/images/`)
2. **Name them with the product code**, for example:

   - `8-94156-052-0.jpg` (Cylindrical Air Filter)
   - `17801-20040.jpg` (Amazon Filter 17801 20040)
   - `17801-22020.jpg` (Amazon Filter 17801 22020)
   - `51010.jpg` (Heavy Duty Oil Filter)
   - `31010.jpg` (Diesel Fuel Filter)
   - `81010.jpg` (Hydraulic Return Filter)

3. **Supported formats**: JPG, PNG, GIF
4. **Recommended size**: 400x300 pixels or similar aspect ratio

## Using Images in Admin:

1. Go to Admin Dashboard (`/admin/login`)
2. Login with: `admin` / `admin123`
3. Click "Add Product" or edit existing products
4. In the "Product Image" section, use the file path: `/images/[product-code].jpg`
5. Or upload directly using the file upload feature

## Current Placeholder Images:

The website currently shows placeholder images with product names. Once you upload real images, they will automatically display instead of the placeholders.
