# Industry Images Directory

This directory contains images for different industries served by Amazon Filtration.

## Required Industry Images:

1. **Automotive** - `automotive.jpg` (Cars, trucks, buses, commercial vehicles)
2. **Construction** - `construction.jpg` (Excavators, loaders, bulldozers, heavy machinery)
3. **Agriculture** - `agriculture.jpg` (Tractors, harvesters, farming equipment)
4. **Power & Energy** - `power-energy.jpg` (Generators, power plants, energy systems)
5. **Manufacturing** - `manufacturing.jpg` (Industrial equipment, hydraulic systems)
6. **Marine & Offshore** - `marine-offshore.jpg` (Ships, marine equipment, offshore)

## Image Specifications:

- **Size**: 600x400 pixels (3:2 aspect ratio)
- **Format**: JPG or PNG
- **Quality**: High resolution for web display
- **Content**: Professional images representing each industry
