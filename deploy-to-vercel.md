## **Step-by-Step Deployment:**

### **1. Create GitHub Repository (5 minutes)**

1. Go to [github.com](https://github.com) and sign in
2. Click **"New repository"** (green button)
3. Repository name: `amazon-filtration-website`
4. Description: `Amazon Filtration (K) Ltd - Professional Website`
5. Make it **Public** ✅
6. **Don't** check "Initialize with README"
7. Click **"Create repository"**

### **2. Upload to GitHub (2 minutes)**

Copy and paste these commands in your terminal:

```bash
# Add your GitHub repository (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/amazon-filtration-website.git

# Push to GitHub
git branch -M main
git push -u origin main
```

**Replace `YOUR_USERNAME` with your actual GitHub username!**

### **3. Deploy to Vercel (3 minutes)**

1. Go to [vercel.com](https://vercel.com)
2. Click **"Sign up"** and choose **"Continue with GitHub"**
3. Click **"New Project"**
4. Find your `amazon-filtration-website` repository
5. Click **"Import"**
6. **Settings:**
   - Framework: **Create React App** ✅
   - Root Directory: `./` (default)
   - Build Command: `npm run build` ✅
   - Output Directory: `build` ✅
7. Click **"Deploy"**

### **4. Get Your Live URL (1 minute)**

- Wait 2-3 minutes for deployment
- You'll get a URL like: `https://amazon-filtration-website.vercel.app`
- **This is your live website!** 🎉

## **Need Help?**

### **If GitHub Upload Fails:**

- Make sure you created the repository first
- Check your GitHub username is correct
- Try: `git remote -v` to see current remotes

### **If Vercel Deployment Fails:**

- Make sure repository is public
- Check build logs in Vercel dashboard
- Try redeploying

### **If Website Doesn't Load:**

- Wait 5-10 minutes for DNS propagation
- Check Vercel dashboard for errors
- Try refreshing the page
